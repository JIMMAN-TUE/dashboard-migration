ทำ "Hand over" ใน `docs/ACCOUNT_SWITCH_PROTOCOL.md` ทุกข้อ: commit เฉพาะงานที่เทสต์แล้ว (งานค้างให้เขียนจุดที่หยุดและคำสั่งถัดไปใน *Next step*) ·
อัปเดต `HANDOFF.md` (status, Table map, checklist, ปัญหา, *Next step*, ผลที่ฉันวางในแชต) + หนึ่งบรรทัดใน `LOG.md` ใน commit เดียวกัน ·
ตั้ง *Working now* = `nobody` · `git pull --rebase` แล้ว push · เช็ค `git status` สะอาดและ origin/main = HEAD
แล้วบอกฉันเป็นภาษาไทยสั้น ๆ: commit, ทำอะไรเสร็จ, ต้องพิมพ์อะไรใน account ถัดไป

โน้ตถึง account ถัดไป: $ARGUMENTS
